Política de Privacidad

Última actualización:

1. Información que recopilamos

El bot CassTroMusic solo recopila información necesaria para su funcionamiento:

  • ID de usuario de Discord
  • ID de servidor (cuando se usa en servidores)
  • Comandos utilizados (para mejorar el servicio)

2. Cómo usamos la información

La información se utiliza únicamente para:

  • Proporcionar funcionalidad de música en IMVU

3. Compartir información

No compartimos tu información con terceros. Los datos se mantienen seguros y solo se usan internamente.

4. Tus derechos

Puedes solicitar la eliminación de tus datos contactando al desarrollador.
